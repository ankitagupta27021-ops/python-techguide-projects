# Python Mini Projects Suite

A collection of interactive Command-Line Interface (CLI) applications built using Python for my internship.

## Projects Included

### 1. Simple Calculator (`simplecalculator.py`)

-Accepts user input for two numbers.

-Supports primary arithmetic operations:

Addition (+)

Subtraction (-)

Multiplication (*)

Division (/)

-Handles division-by-zero checks.
  
### 2. Number Guessing Game (`numberguessinggame.py`)

-Uses Python's built-in random module to select a target number.

-Compares user input against the secret number.

-Provides immediate feedback (Too low!, Too high!, or Congratulations!).

  ### 1. To-Do List Application (`todo.py`)
  
- Dynamic menu interface with task status tracking (`Pending` vs `Done`).
- Add, complete, and delete tasks with full error validation.
